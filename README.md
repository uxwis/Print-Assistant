# 印刷助手（Print Assistant CN）1.3.0

在 Figma 中设置实际成品尺寸，完成印刷预检、出血与裁切线、ICC 软打样和 CMYK PDF 导出。全中文界面，单位为毫米，色彩转换在本地运行，文件不上云。

界面更新：插件窗口改为 480×560，采用白色背景与简洁页签。导出页优先显示色彩配置、DPI 和输出方式，分辨率与输出方式的提示紧跟标题，以中文括号显示并随选项更新。出血、裁切线、红色出血框与安全边距集中在“出血与裁切”中，点击展开编辑；移除其与输出方式之间的分割线。当前出血与开启的标记直接显示在折叠摘要中；导出按钮固定在底部，按钮上方无分割线，尺寸未就绪提示显示在按钮下方。软打样说明按需展开。仍兼容 360px 窄窗口。

`community/` 保存与新版界面配套的社区发布封面、三张展示图、图标与中文文案；封面和展示图均为 1920×1080，使用当前插件界面与标注的示例内容。修改界面后，可运行 `node community/生成素材.mjs` 更新展示图。

1.3.0 合并成品尺寸与原稿调整，增加标准尺寸选择并精简小数显示；未设成品尺寸也可按参考尺寸导出。导出只使用临时副本，成功或失败后自动清理，保留已有原稿和旧印刷版。修复 JPEG 过滤器数组、连续解码与蒙版反相函数导致的矢量导出失败，并修正裁切标记的坐标，恢复可独立关闭的红色出血框。保留动态页面启动修复。

## 页面功能

1. 选中一个或多个原稿画板，打开插件即进入 **画板** 页，在 **设置实际印刷尺寸** 中选择标准尺寸或输入宽高，统一点击一次 **设置尺寸**。未设置尺寸的画板会按比例自动填入匹配预置（支持横竖方向及标准画板的整数像素取整），下拉框同步显示预置名称；未匹配时留空供自定义输入。匹配仅产生待确认草稿，点击保存才生效，不覆盖已有尺寸或手动输入。同一比例匹配多个尺寸时，优先标准像素尺寸，再比较比例误差和按 72 DPI 换算的尺寸距离，实际尺寸仍需确认。首个尺寸输入按原比例联动；手动修改另一边可设定自定义比例。比例不一致时才显示 **按成品比例调整原稿（比例不一致，建议勾选）**，勾选后可选择 **等比缩放内容**。不知道成品尺寸时，可跳过这一步。
2. **预检** 页可独立检查当前原稿，点击 **开始预检**；**生成软打样** 用于检查色彩模拟。
3. **导出** 页可独立选择印刷 ICC 和 150 / 300 / 600 DPI，默认 300 DPI。三个 Tab 可自由切换，无需按固定顺序使用。
4. 在 **导出** 页设置出血、裁切线、红色出血框与输出方式，点击 **导出 CMYK PDF**。仅导出当前选中的原稿画板；未选中时不可导出。导出完成后下载文件，临时副本自动清理。

插件默认打开画板页，不再区分新建／已有画板页签。未选择画板时，显示选择原稿的提示和 **新建画板** 入口；选中或新建完成后，直接显示实际印刷尺寸设置并隐藏新建入口。原稿调整复用同一套尺寸输入，不再有重复表单。标准尺寸选择会填入所有选中行；比例不一致时，需启用原稿调整才能保存。未填写尺寸、未选中画板或全部比例一致时，隐藏原稿调整与内容缩放；批量选择只要有一个比例不一致就显示调整选项。恢复一致或完成调整后自动隐藏并取消勾选。已有画板按自身像素比例对应成品尺寸，不会按毫米换算放大原稿。例如，3000×2500px 对应 3000×2500mm 时原稿与内容保持不变。比例不同时保留原稿宽度，按新比例调整高度，调整后的像素宽高取整数；界面显示保存后的原稿尺寸。新建、调整都会同步保存成品毫米尺寸。勾选等比缩放内容时，以能放入新画板的比例缩放，保留内容比例。PDF 仍按保存的成品毫米尺寸导出。

尺寸显示为整数，手动输入按整数毫米取整；比例联动和已保存尺寸保留内部计算精度。A4 预设为准确的 210×297mm；595×842px 等标准画板的整数像素取整误差不会再产生 297.176471 这样的输入结果。保存时允许整数像素取整带来的比例误差；不会给未设置的画板自动保存成品尺寸。

预检和导出只显示尺寸摘要：单画板显示“实际印刷尺寸：90 × 54 mm”，多个画板显示“3 个画板 · 2 个已设置”。点击 **修改／去设置** 返回画板页。尺寸草稿在切换页签、切换选择时保留；当前选中画板有未保存修改时，需先通过 **去设置** 返回画板页保存。

批量保存只提交当前选中且修改过的行。所有修改项通过校验后才统一写入；任一行无效、原稿在编辑期间改变或画板不可用时，整批不保存，并标出对应行。调整原稿前会先验证临时副本及所需字体。未填写且未修改的行保持未设置，不自动套用其他画板尺寸。已有尺寸记录直接沿用，无需迁移。

## 实际尺寸与 DPI

- 每个原稿画板独立保存成品尺寸；只在画板页编辑，预检页与导出页共用，关闭插件后仍可恢复已保存的尺寸。未保存草稿只保留在本次会话。
- 不根据画板名称或像素大小猜测已有画板的实际打印尺寸。尚未设置尺寸时，预检与导出页显示“检测尺寸”，按当前画板像素以 72 DPI 换算；可直接点击“开始预检”，以该尺寸完整检查 DPI、字号、线宽和安全边距，不自动保存尺寸。已设置尺寸失效或存在尚未应用的已设尺寸修改时，需先设置或重新确认。
- 未设置尺寸时跳过图片 DPI、实际字号、细线和安全区检查。多色黑文字仅作色值提示，待设置尺寸后再判断是否属于小字。
- 未设尺寸可以导出：沿用原稿默认的 `1 px = 1 pt = 1/72 inch` 比例，导出页显示参考毫米尺寸，不将该参考值保存为已确认的成品尺寸。切换 150／300／600 DPI 不改变参考页面大小。预检仍跳过未确认尺寸的物理检查。
- 原稿宽高改变后，已保存的旧尺寸显示为失效，需重新确认。点击对应行 **重新确认**，按当前比例更新草稿，再统一保存；也可重新输入宽高。
- **有效 DPI = 原图像素数 ÷ 实际放置长度（英寸）**。例如，1000px 宽的图片完整印成 50mm 宽，有效约 508 DPI；该数值不依赖导出文件的 DPI 标签。
- 图片按 FILL / FIT / CROP / TILE、旋转、裁切、嵌套缩放与完整仿射变换计算。裁切放大只使用原图的一部分，不会增加有效细节。非等比变换取较低的有效分辨率。
- 检查包括画板背景图片，忽略隐藏内容。图片预检建议值为所选 DPI 与 200 DPI 中的较小值；低于建议值一半才报错，其余不足为警告。300／600 DPI 导出时，图片低于 200 DPI 提醒、低于 100 DPI 报错。
- 字号、描边和安全边距按真实成品比例换算。安全边距使用文字渲染范围，提示距成品边缘的距离；出血在裁切线外，不增加成品内的安全边距。尺寸、DPI、安全边距、手动选择范围或原稿变化后，旧预检结果失效；点击“定位图层”保留预检结果，尺寸摘要同步到当前选中画板。

| 设置 | 用途提示 |
|---|---|
| 150 DPI · 大幅远看 | 大幅海报、展架等远距离观看用途 |
| 300 DPI · 常规印刷 | 名片、宣传单、画册等常规印刷，默认推荐 |
| 600 DPI · 精细位图 | 细节要求较高的位图或整页栅格文件，文件较大 |

提高导出 DPI 不会增加原图细节。矢量文字和图形的边缘清晰度不受 DPI 限制；提高导出 DPI 不会让图片预检更严苛。

## 预检项目

| 项目 | 行为 |
|---|---|
| 图片分辨率 | 按实际放置尺寸检查有效 DPI，支持定位图层 |
| 字体缺失 | 检查 Figma 可用字体；矢量导出无法转曲时明确报错 |
| 小字四色黑 | 按实际字号与估算 CMYK 检查，可一键转单黑 |
| 小字与细线 | 实际字号低于 5pt、描边低于 0.25pt 时提示 |
| 安全区 | 文字按最外层原稿画板与真实毫米安全边距检查 |
| 阴影、模糊 | 提示原生局部位图；导出检查其实际有效 DPI |

预检中的 CMYK 数值为数学估算，用于问题提示；正式导出使用真实 ICC 分色。

## ICC 与软打样

下拉框只有三个选项：

- ISO Coated v2 300%（ECI / FOGRA39），默认配置。
- ISO Coated v2（ECI / FOGRA39）。
- **导入印厂／设备 CMYK ICC**，统一原来的国标、数码快印和其他导入入口。

导入入口使用同一套验证规则：接受完整的 CMYK 输出设备 `.icc` / `.icm`，文件不超过 32 MB，拒绝 RGB、DeviceLink、损坏或缺少所需转换表的配置。显示已载入文件名，可替换；导入文件仅在当前插件会话内保存，不上传网络。

软打样预览选中画板中的第一个，执行 sRGB → 所选 CMYK ICC → sRGB 的往返转换。该预览使用整页合成图；矢量导出按对象转换颜色，透明叠加处可能与预览略有差异。屏幕与最终设备、纸张的实际输出仍以印厂打样为准。

## 两种 CMYK PDF

### 矢量优先（默认）

- 按成品尺寸缩放原稿副本，生成毫米单位的出血与裁切线，原稿不被修改。
- 在临时导出副本中加载混合字体、处理组件实例并冻结自动布局，再将文字转为矢量路径。原稿中的文字保持原有类型，临时副本在成功和失败后均清理。
- 以 Figma 原生 PDF 为基础，按页面、Form 与资源作用域解析颜色，维护图形状态，通过 LittleCMS 将源色彩转换到所选 ICC。
- 保留普通路径、裁切、正常透明度以及线性／径向渐变。渐变函数支持 Type 0／2／3／4，Type 4 计算表达式在受限解释器中求值后转换为 CMYK 采样函数，仍保留矢量渐变；支持条件分支、栈操作、算术及逻辑计算，不执行 PDF 中的任意 JavaScript。支持灰度／RGB／CMYK／ICC 亮度蒙版及其中的 Pattern 渐变、彩色图片和嵌套透明蒙版、图片透明蒙版、Flate 图片预测器，以及灰度／RGB JPEG 的单个过滤器、过滤器数组与前置压缩解码。蒙版的合法传递函数保留给 PDF 阅读器执行，包括反相用的 Type 4 函数，不会删除透明度效果来绕过错误。
- 照片按所选 DPI 适当降采样，按同一图片的最大实际使用尺寸保留足够像素，蒙版同步处理；低分辨率照片不强行放大。
- 阴影、模糊保留 Figma 原生效果位图并报告实际有效 DPI。原生 PDF 没有可指定效果采样 DPI 的插件参数，因此提高设置值不会自动增加效果位图细节。
- 不支持的混合模式、网格／复杂渐变、颜色结构、内联图像或特殊编码会明确报错，提供 **切换整页栅格模式** 按钮；不会静默把整页变成图片。
- 文字／图形为主的文件通常更紧凑；复杂文字转曲与图片内容会影响体积，不保证所有文件都更小。

### 整页栅格

先由 Figma 按所选 DPI 正确合成整页透明度、渐变和阴影，再通过 LittleCMS 转为四通道 CMYK。适用于复杂效果的兼容输出，文字与图形也会变成图片。单边超过 16384 像素或超过 4000 万像素时，需要降低 DPI 或拆分画板。

两种模式均使用相对色度意图与黑点补偿，嵌入实际目标 ICC，写入相同的成品框 TrimBox 和出血框 BleedBox。切换 DPI 不改变 PDF 物理尺寸。图片／渐变及矢量颜色引用四通道目标 ICC；亮度蒙版保留源颜色空间、渐变函数、背景色及像素数据以保持透明度计算，图片透明通道保持灰度数据。蒙版内的 RGB 资源用于计算透明度，不会作为页面油墨颜色转换。不宣称通过 PDF/X 全项认证。

## 出血与裁切标记

导出页设置出血（默认 3mm）、裁切线、出血框和预检安全边距。裁切线是四角八条黑色短线，长度固定 5mm，偏移为出血与 3mm 中的较大值；外侧红框表示出血边界，可独立开关。两者默认开启。PDF 的 TrimBox、BleedBox 同时记录真实成品与出血范围。

导出在临时副本上完成排版与标记，随后自动清理，不在画布留下新印刷版，也不删除已有印刷版。说明界面改为简短段落，图片分辨率提示按需展开查看。

纯色背景自动延伸至出血区；图片／渐变背景仍需设计师在原稿中准备足够的出血内容。当前版本未提供专色、烫金、模切和拼大版。

## 安装与构建

直接使用：解压 **印前助手_可直接导入.zip**，在 Figma 桌面端通过 Plugins → Development → Import plugin from manifest… 选择其中的 `manifest.json`。源码构建后应导入 `dist/manifest.json`。

```bash
npm install
npm run build
npm run watch
npm run package
```

构建生成自包含 `dist/ui.html`，LittleCMS WASM 和内置 ICC 均内联，保持 `networkAccess: none`。第三方授权见 `assets/licenses`，安装包附带 `THIRD_PARTY_NOTICES.txt`。
`npm run package` 在 Windows 上重新构建并生成安装／源码两个压缩包，源码包不包含依赖和临时测试输出。
